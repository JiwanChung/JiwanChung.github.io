# CV

LaTeX source for Jiwan Chung's CV. Build with `./build.sh` (incremental) or
`./build.sh full` (clean rebuild — required when changing `\nocite{}` or the
custom biblatex drivers).

For the edit protocol — adding a publication, the bold-author convention, the
section structure, known gotchas — see [CLAUDE.md](CLAUDE.md). That's the
source of truth; this README is just a pointer.
